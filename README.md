- **Overview**: Embedded C++ system for high-altitude sky brightness measurements on BeagleBone hardware.  
- **Technologies**: C++, Linux (Armbian), GCC, GDB  
- **Key Contributions**:  
  - Implemented real-time error correction and redundant data storage to ensure 100% retention.  
  - Collaborated with CSA/MDA engineers to validate system resilience under vacuum, vibration, and extreme temperature tests.  
  - Optimized data acquisition pipeline, improving imaging accuracy by 25%.  

### **[DE10 Battleship Game](https://github.com/GauravMoturi/DE-10-Battleship)**
- **Overview**: Interactive two-player Battleship game implemented on FPGA hardware.  
- **Technologies**: Verilog HDL, FPGA (DE10-Lite), Quartus, VGA  
- **Key Contributions**:  
  - Designed finite state machines for turn-based game logic and real-time hit/miss detection.  
  - Mapped physical inputs and VGA outputs for interactive gameplay.  
  - Debugged FPGA implementation using Quartus simulation tools to ensure stable performance.
